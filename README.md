# 积分的新方法 · New Methods of Integration

**作者 / Author**　周泽民（无理函数君，James Zhou）

本书分上下两编。上编从函数单元出发构造原函数，下编介绍定积分的求值方法，涵盖对称性、参数法与积分变换。全书配有例题、练习和参考解答。

This book is divided into two parts. The first develops methods for constructing antiderivatives from function units. The second covers techniques for evaluating definite integrals, including symmetry, parameter methods, and integral transforms. Both parts include worked examples, exercises, and solutions.
